# What I Need to Do

一款基于四象限法则的 macOS 桌面待办应用：常驻系统托盘、快捷键随时呼出，未完成的事项不会在第二天消失，而是自动延续并标注「已拖 N 天」。

---

## 一、为什么做这个

日常使用主流待办工具时，我反复遇到两个问题：

**痛点一：未完成的任务在次日「消失」。**
多数「今日待办」类应用以自然日为边界，今天没做完的事第二天不会主动出现在视野里，只能靠自己回忆或翻历史记录。结果是——真正被拖延的事，恰恰是最容易被系统遗忘的事。

**痛点二：所有任务被平铺成一份清单，缺少优先级。**
「回复一封邮件」和「完成季度方案」在列表里长得一模一样。缺少「重要 / 紧急」两个维度的区分，人天然会先做容易的、急的，把真正重要但不紧急的事一再往后推。

## 二、这个应用如何解决

| 痛点 | 解决方案 |
| --- | --- |
| 任务没有优先级 | 采用**艾森豪威尔四象限**（重要·紧急 / 重要·不急 / 急·不重要 / 都不是）分类，网格视图直接把四个象限并列呈现，一眼看清精力该放在哪里 |
| 重要的事被急事挤掉 | 列表视图按「未完成优先 → 象限序号 → 拖延天数」自动排序，优先级最高的任务永远在最上方 |
| 未完成任务次日消失 | 每条任务记录首次创建日期（`firstDate`）。未完成的任务**自动延续到今天**，并显示**「已拖 N 天」**标签；超过 3 天会高亮为警示色。已完成的任务当天归档，次日自动从视图中移除，保持界面清爽 |

核心设计原则：**完成的事会走，没完成的事不会走。** 拖延不再是无声的，而是被明确计数并呈现出来。

## 三、技术栈

- **前端**：原生 HTML / CSS / JavaScript，无框架、无构建步骤，全部逻辑与样式集中在单文件 `src/index.html`
- **数据**：`localStorage` 本地持久化，无后端、无账号、数据不出本机
- **桌面端**：[Tauri v2](https://tauri.app)（Rust）打包为 macOS 原生应用（`.app` / `.dmg`），相比 Electron 体积更小、内存占用更低
- **系统集成**（`src-tauri/src/main.rs`）：
  - 系统托盘常驻：左键单击显示 / 隐藏窗口，右键弹出菜单
  - 全局快捷键 `⌘ + Shift + T`：在任意应用中呼出或收起窗口
  - 点击窗口关闭按钮时隐藏到托盘而非退出，符合常驻工具的使用直觉

> 代码同时兼容 Windows（`Win + Shift + T`，产出 `.msi` / `.exe`），但主要在 macOS 上开发与验证。

## 四、主要功能

- **四象限分类**：添加时选择象限，或在输入框以 `!1` ~ `!4` 开头快速归类
- **双视图切换**：网格视图（四象限全局概览）与列表视图（按优先级线性排序），视图偏好本地记忆
- **拖延可视化**：未完成任务自动跨日延续，实时显示「已拖 N 天」，≥ 3 天高亮提醒
- **快速编辑**：点击彩色数字循环切换象限；双击标题或点击 ✎ 就地改名；✕ 删除
- **键盘优先**：输入框自动聚焦，回车连续添加，编辑态 `Enter` 保存 / `Esc` 取消
- **每日归档**：已完成任务当天保留可查、次日自动隐藏
- **状态提示**：顶栏根据剩余任务数量给出即时反馈
- **系统托盘 + 全局快捷键**：随时呼出，不打断当前工作流

## 五、如何运行

**环境要求**：Node.js（LTS）、Rust（[rustup.rs](https://rustup.rs)）、Xcode 命令行工具（`xcode-select --install`）。

```bash
# 1. 安装依赖
npm install

# 2. 开发模式运行（首次编译 Rust 需要几分钟，之后为增量编译）
npm run dev

# 3. 打包为 macOS 应用
npm run build
```

打包产物位于 `src-tauri/target/release/bundle/`（macOS 下为 `.dmg` 与 `.app`）。

如需替换应用图标，将源图放在根目录后执行 `npm run icon`，会自动生成各尺寸图标。

## 六、目录结构

```
today-todo/
├─ package.json              # 脚本与 Tauri CLI 依赖
├─ src/
│  └─ index.html             # 前端全部实现（UI + 逻辑 + 样式）
└─ src-tauri/
   ├─ Cargo.toml             # Rust 依赖
   ├─ tauri.conf.json        # 窗口与打包配置
   ├─ capabilities/          # 权限声明
   ├─ icons/                 # 应用图标
   └─ src/
      └─ main.rs             # 托盘、全局快捷键、关闭即隐藏
```
